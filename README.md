# API-REST-NODE.JS

## Descrição
Projeto de API REST utilizando Node.js e Fastify. Este projeto utiliza TypeScript para tipagem e ESLint para linting do código.

---

- **name**: `api-rest-node.js`  
  Nome do projeto.

- **version**: `1.0.0`  
  Versão inicial do projeto.

- **description**: `API-REST-NODE.JS`  
  Descrição do projeto.

- **main**: `index.js`  
  Arquivo de entrada principal.

- **scripts**:  
  Comandos configurados para o desenvolvimento:
  - `dev`: Inicia o servidor em modo de observação usando o `tsx`.
  - `lint`: Executa o ESLint na pasta `src` para arquivos com extensão `.ts` e corrige automaticamente os problemas encontrados.
